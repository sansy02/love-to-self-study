# 爱学

一个只属于你的学习路线：把英文课件变成你听得懂的课，按你的情况安排每天学什么，一直陪你到考完。

在线使用：https://love-to-self-study.vercel.app（不用注册，打开就能用）

爱学是给**在英文授课的大学读书、英语还不太够用的同学**做的：上课跟不上、课件看不懂、不知道考试怎么用英文答题。把一门课的资料放进来，爱学按你的学习方式一页一页讲给你听，每天给你排好要做的几步，错的地方第二天再考一次。

> NotebookLM 帮你看懂资料；爱学帮你考过这门课。

---

## 三步开始

1. **新建一门课**：输入课程名（例如 `BIC3133 Object Oriented Methods`），考试日期可以以后再填。
2. **回答 5 个问题**：目标、英文程度、喜欢怎么学、每天多少时间、讲解长短。讲解和路线都会按你的回答来。
3. **把资料放进来**：老师课件、Tutorial 题目、往年考试题、其他笔记，选好类型、填第几周再上传。之后每天打开「路线」，照着做就行。

还没有资料？在首页点「先看示例课程」，里面有一份示例课件和一份示例考卷，不用上传，也不耗次数。

## 怎么用

### 路线（每门课的第一个标签）

每天按你的问卷和学习数据，排出今天要做的几步，每一步都写着为什么排它：

- 有到期的错题，先复习
- 需要加强的知识点：喜欢先弄懂的人先「补一补」，喜欢先做题的人先练原题
- 往年常考、还没掌握的知识点：练相关原题
- 还没学完的课件按周往下学；学完的课件做诊断小测
- 离考试 14 天以内自动进入冲刺模式，常考点优先

做完的步骤会自动打勾。路线当天固定，不会一刷新就变；想按最新情况重排，点「按现在的情况重新排」。

### 课程里的其他标签

| 标签 | 用来做什么 |
|------|-----------|
| 资料 | 这门课的所有资料，按周排列；「⋯」可以改类型、周数，或移到别的课 |
| 知识点 | 整门课的掌握地图：需要加强 / 学习中 / 还没练过 / 已掌握 |
| 考试 | 把 Tutorial 和往年考试题「整理成题库」，看高频考点排行，按知识点练原题 |
| 复习 | 这门课今天要复习的错题 |

### 逐页学习

- 电脑上左边是原页面，右边是讲解；手机上用「讲解 / 原页面」切换。
- 讲解按你的学习方式生成：英文吃力就全中文并逐句翻译关键句；喜欢先看定义就先给中英对照的定义；选了「越短越好」就只讲重点。
- 每页先看「一句话」，再看讲解、例子和考试提示。哪里不懂，在「追问这一页」里直接问。
- 术语点 ☆ 收藏，之后会出现在「术语卡片」里。翻页可以用键盘 ← →。

### 练习、诊断和题库

- **诊断小测**：学完一讲时出现，5 道选择 / 填空题，告诉你哪些知识点还没掌握。
- **练习这一章 / 整讲练习**：英文考试题。简答题可以先写中文，会帮你改成英文高分答案。
- **题库**：从你的 Tutorial 和往年考试题里拆出来的原题，带题号和分值，简答题附 AI 参考答案（仅供参考）。
- 答错时可以选「为什么错了」。AI 会先猜一个，不对可以自己改；这些原因会影响你的路线。

**怎么算掌握**：在两个不同的日子都答对，并且至少一次是选择题或填空题。错一次只算「学习中」，在两个不同的日子都答错才算「需要加强」。简答题由 AI 打分，只作参考。

### 学习画像

在「学习画像」里可以看到：连续学习天数、最近 4 周的学习日历、你最常怎么错、最需要加强的知识点、每门课掌握了多少，以及爱学根据你的情况做了哪些调整。全部只用你自己的数据，别人看不到。

### 换设备继续学

不用注册账号。在「我的 → 换设备继续学习」里生成一个找回码，在新设备的首页点「换了设备？用找回码继续之前的学习」输入即可。找回码只显示一次，请保存好，不要发给别人。

### 免费次数和自己的 Key

- 每天有免费的 AI 次数，北京时间 0 点重置。打开没讲过的页、追问、出题、批改、整理题库才计次；已经生成过的讲解和示例课程不计次。
- 想不限次数：在「我的 → AI 次数」里填入自己的 DeepSeek Key（`sk-` 开头）或 Gemini Key（`AIza` 开头），加密保存。

## 常见问题

**第一次打开很慢？** 免费服务器闲置后会休眠，第一次打开要等 30 秒左右。

**上传失败？** 只支持 PPTX、PDF、DOCX，每个文件最大 20MB。旧版 .ppt / .doc 请先「另存为」新格式。扫描版 PDF 读不到文字，请换成带文字的版本。

**提示「AI 暂时连不上」？** 免费模型太忙了，等十几秒点「重试」，或者填自己的 Key。

**别人能看到我的东西吗？** 不能。你的课程、问卷、路线、追问、练习、错题、收藏和学习画像只有你自己能看到。为了省 AI 次数，同一份课件、同一种讲解方式的讲解只生成一次，之后直接复用。

## 开发者

| 层级 | 技术 |
|------|------|
| 前端 | React 19 + TypeScript + Vite + Tailwind CSS（部署在 Vercel，Root Directory 为 `frontend`） |
| 后端 | Python FastAPI（部署在 Render） |
| 数据库 | SQLite（本地）/ PostgreSQL（线上），启动时自动补齐新表和新字段 |
| AI | Gemini（主力，能看图）→ 智谱 GLM（备用），出错自动切换；也支持用户自己的 DeepSeek / Gemini Key |

### 本地运行

```bash
# 后端
cd backend
python -m venv venv
source venv/Scripts/activate      # Windows
pip install -r requirements.txt
python -m uvicorn main:app --port 8000

# 前端（另开一个终端）
cd frontend
npm install
npm run dev
```

### 环境变量（参考 `backend/env.example`）

| 变量 | 说明 |
|------|------|
| `JWT_SECRET` | 必填，至少 32 位随机字符 |
| `GEMINI_API_KEY` | 免费主力模型 |
| `GLM_API_KEY` | 免费备用模型 |
| `FREE_DAILY_LIMIT` | 每人每天免费次数，默认 60 |
| `AUTH_MODE` | 默认 `anonymous`（不用注册）；改成 `account` 或 `both` 可重新开放账号登录（前端同时设置 `VITE_ENABLE_LOGIN=true`） |

### 测试和预览

```bash
cd backend
python -m unittest discover -s tests -v      # 后端测试

cd frontend
bash preview/build-preview.sh                # 打包一个不连服务器的预览网页：preview/dist/aixue-preview.html
```

